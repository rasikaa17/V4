# AI-Powered Threat Intelligence Platform for Prioritizing Actionable Cyber Threats

Final-year B.Tech (Cybersecurity) academic project. Built in phases; this README
will be expanded into full project documentation once all phases are complete.

## Current Status: Phase 1 — Project Setup ✅

Basic Flask application scaffold is working. See project root for the full
planned folder structure (data/, models/, database/, ml/, routes/, templates/,
static/, tests/) — most of these are placeholders until their corresponding
phase is implemented.

## Installation

```bash
python -m venv venv
venv\Scripts\activate        (Windows)
source venv/bin/activate     (Mac/Linux)

pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Visit http://127.0.0.1:5000 in your browser.
